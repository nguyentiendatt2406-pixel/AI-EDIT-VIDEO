# AI Edit Video

Kho skill Claude Code để dựng và chỉnh sửa video bằng AI (HTML + GSAP, phụ đề, chuyển cảnh, âm thanh).

## Claude Code skills

Thư mục `.claude/skills/` được commit vào repo nên mọi phiên Claude Code mở repo này
(Mac, web claude.ai/code, app điện thoại) đều tự nạp skill — không cần cài riêng từng máy.

| Skill | Dùng để | Nguồn |
|---|---|---|
| `hyperframes` | Dựng video bằng HTML + GSAP: cảnh, chữ động, phụ đề karaoke, chuyển cảnh, âm thanh | [notivn/AIEVv2](https://github.com/notivn/AIEVv2) (MIT) |

Cập nhật skill: chép lại thư mục `.claude/skills/hyperframes` từ repo nguồn rồi commit.
